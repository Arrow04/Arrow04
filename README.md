> **Architecture:** Django | PostgreSQL | React | Redis

* Integrated complex workflows including attendance tracking, leave encashment, statutory deductions (PF, ESI, PT), and automated Form 16 PDF generation.

### 02. Automated Network Host Isolator
> **Architecture:** Go | System-level Networking | SIEM Integration
* Built a lightweight, high-performance host isolation security agent designed to immediately execute network containment upon receiving SIEM threat alerts.
* Optimized for low-latency response to prevent lateral movement during active security incidents.

> **Architecture:** Next.js | TypeScript | Vercel
